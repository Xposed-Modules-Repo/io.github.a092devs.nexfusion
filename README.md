# NexFusion

NexFusion is an open-source LSPosed runtime patch manager and module framework with a Material Design interface. It applies in-memory bytecode hooks dynamically using libxposed and DexKit to supported apps (YouTube, YouTube Music, Reddit, Instagram, Telegram, Gboard, etc.) without modifying original APK files or breaking Play Store signatures.

## Features
- **Dynamic In-Memory Bytecode Hooks**: Integrates with DexKit and libxposed for runtime patch execution.
- **Modular Patch Bundles**: Download and manage patches modularly without rebuilding APKs.
- **Clean Material You UI**: Smooth fluid animations, adaptive landscape layout, and customizable themes.
- **LSPosed Integration**: Compatible with LSPosed on Android 8.1 - 15+.
